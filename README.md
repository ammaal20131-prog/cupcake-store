# متجر الكب كيك 🧁

مشروع قواعد بيانات لطالبات المرحلة المتوسطة. تبني الطالبة من الجوال قاعدة بيانات لمتجر كب كيك خاص بها، في خمس خطوات:

1. **الجداول**: المنتجات، الزبونات، الطلبات
2. **العلاقات**: واحد إلى متعدد
3. **النماذج**: إدخال السجلات
4. **الاستعلامات**: شرط وترتيب
5. **التقارير**: تجميع ومجموع

ثم تعبّئ ورقة العمل داخل التطبيق، وتنسخ ملخص عملها وترسله للمعلمة.

**رابط التطبيق:** https://ammaal20131-prog.github.io/cupcake-store/

**دليل الطالبة بالصور:** https://ammaal20131-prog.github.io/cupcake-store/guide.pdf

البيانات تُحفظ على جهاز كل طالبة فقط.
